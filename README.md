# 用途別画像リサイズ Ver.3.1

店内モニター、WEB・SNS、印刷向けの画像をブラウザ内でまとめて変換します。外部API・課金・新規サーバーは不要です。画像を外部へ送信しません。

## 今回の更新

明るいテクスチャ帯を5種類追加しました。

|種類|仕上がり|
|---|---|
|光沢・サテン|柔らかな光の流れと広い光沢|
|パール|白い光がにじむような淡い質感|
|紙・布|細かな織り目の質感|
|明るい幾何学|半透明の図形と明るいライン|
|シンプル|模様を抑えた柔らかな2色の変化|

従来の単色・グラデーション・画像ぼかし・ストライプ・ドット・幾何学も残しています。

## 使い方

1. 出力用途を選び、画像を追加します。
2. 「帯を追加」を選びます。初期状態では「明るめ」の色で、サテン→パール→紙・布→明るい幾何学が画像の追加順に切り替わります。
3. テクスチャ見本をクリックすると、その質感を共通デザインとして選べます。画像ごとの指定はそのまま優先されます。
4. 「明るさ（自動カラー）」で「明るめ／標準／落ち着いた」を選びます。
5. 色を自分で決める場合は「手動カラー指定」で主色・アクセント色を指定します。手動カラーは指定色をそのまま使い、明るさ選択は無効になります。質感自体の白い光沢や模様は重なります。
6. 「画像との境界に明るいラインを入れる」で縁取りを切り替えられます。ラインも余白内だけに描きます。
7. 仕上がりプレビューを確認して、個別画像の↓、または一括保存ボタンから保存します。

### 複数画像の帯

- 共通：選んだデザインを全画像へ適用。帯デザイン「自動選択」なら画像ごとの余白と彩度から質感を選びます。
- 順番切替：チェック候補を画面の並び順で繰り返します。
- ランダム：チェック候補から選びます。画像読み込み時の値を使い、候補が変わらなければプレビューと保存結果は同じです。削除して再追加した場合、ページ再読込後は再抽選します。
- 候補は1種類以上必要です。候補が1種類なら全画像で同じになります。
- 画像一覧の「この画像の帯」で個別指定できます。「一括設定を使用」に戻せば解除できます。
- 同じ画像を複数用途へ出す場合、順番・ランダムの帯は画像単位で共通です。デザイン自動選択は用途ごとの余白を判定します。

### 自動カラー

外周付近の透明・白・黒・無彩色を避け、色の面積・彩度・明るさから主色を選びます。色味が離れた候補をアクセント色に使い、必要なら画像全体も参照します。色が取れない場合は青・ミントの既定色です。自動カラーは明るさ設定に合わせて白または落ち着いた色を混ぜます。画像の意味を理解するAI処理ではありません。色の好みが合わない場合は手動指定へ切り替えてください。

デザイン自動選択は、余白12%未満ならシンプル、低彩度ならパール、55%超ならサテン、それ以外の左右余白なら明るい幾何学、上下余白ならサテンです。自動カラーと別の機能です。

## 元画像の維持

帯追加では、元画像の全体を中央に収めて縦横比を維持します。トリミング・引き伸ばし・再生成は行いません。帯・テクスチャ・境界ラインを元画像内部に重ねません。余白がなければ帯を描きません。文字帯はありません。

元画像の縮小・拡大に伴う通常の再サンプリングとJPG圧縮は発生します。PNGの透明余白設定より帯を優先しますが、元画像内の透明部分は従来の保存設定に従います。

## 維持した出力用途

|用途|サイズ|
|---|---|
|WEB用・軽量|横640px・高さ自動・JPG85%|
|Googleマップ|1200×1200|
|X・正方形|1200×1200|
|X・横型|1200×675|
|LINE|1040×1040|
|モニター・横|1920×1080|
|モニター・縦|1080×1920|
|A4・縦／横|2480×3508／3508×2480|
|A3・縦／横|3508×4961／4961×3508|
|任意サイズ|各辺1～12000px|

WEB用は高さ自動のため、帯追加モードでも帯は付きません。余白、PNG透明余白、背景色、JPG画質、トリミングの上下中央・任意焦点、引き伸ばし、複数画像、画像ごとの用途指定、個別保存、ZIP保存、同名ファイル連番も維持しています。

出力名はCMS向けにハイフンで区切ります。元画像名の空白・アンダースコアもハイフンへ変換します。ZIP名や連番にもアンダースコアを使いません。

## リポジトリ構成

- `index.html`
- `app.js`
- `bands.js`
- `styles.css`
- `jszip.min.js`（従来と同一）
- `textures/`：5種類のオリジナルSVG素材
- `README.md`、`検証結果.md`、`検証ログ.json`、`GitHub反映手順.md`

本番に必要な5ファイルはリポジトリ直下へ置いてください。`textures/` も同じ階層に置く構成です。素材は軽量なSVGで、外部素材・外部ライセンスは使っていません。

PCでHTMLを直接開いた時にも書き出せるよう、SVGと同じデータを `bands.js` 内に内蔵しています。Canvasはこのデータからテクスチャを読み込みます。`textures/` のSVGだけを書き換えても画面には反映されません。変更時は `bands.js` の `BAND_TEXTURE_SOURCES` 内の同じ素材も更新してください。SVG素材は質感レイヤーで、色はツールの配色設定で付きます。

## 処理負荷・対応

プレビューは保存と同じ描画・形式・解像度で生成して縮小表示します。画像・用途・サイズが多いと時間とメモリが増えます。生成は順次処理し、古い設定の結果は表示しません。保存中は設定操作を無効にします。テクスチャが読み込めない場合はグラデーションへ代替します。

GitHub Pagesの公開先・スタッフ実機・Safari／Firefoxは未検証です。公開後の確認方法は反映手順を参照してください。
